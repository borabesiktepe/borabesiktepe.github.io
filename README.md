# borabesiktepe.com

Portfolio of Bora Beşiktepe, digital illustrator from İstanbul.

![Bora Beşiktepe portfolio preview](public/og-image.png)

## Built with

- React + Vite
- React Router
- Framer Motion
- Plain CSS
- GitHub Pages, deployed by GitHub Actions on every push to `main`

## Run locally

```bash
npm install
npm run dev
```
